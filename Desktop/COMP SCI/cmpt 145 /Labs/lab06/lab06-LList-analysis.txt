1. is_empty()
Time Complexity: O(1)
Reasoning: This method simply checks if the size of the list is zero, which is a constant-time operation.
2. size()
Time Complexity: O(1)
Reasoning: The size is stored as an attribute (self._size), so retrieving it is a constant-time operation.
3. prepend(val)
Time Complexity: O(1)
Reasoning: This method creates a new node and adjusts the head of the list. Both operations are done in constant time.
4. append(val)
Time Complexity: O(1)
Reasoning: Since the list maintains a reference to the tail node, appending a new node at the end involves a constant number of operations.
5. retrieve_data(idx)
Time Complexity: O(n)
Reasoning: In the worst case, the method might need to traverse the entire list to reach the node at index idx. This operation is linear in the size of the list.
6. set_data(idx, val)
Time Complexity: O(n)
Reasoning: Similar to retrieve_data(idx), this method may need to traverse the list to find the node at index idx. Thus, it has a linear time complexity.
7. remove_from_front()
Time Complexity: O(1)
Reasoning: Removing the front node only requires updating the head reference, which is done in constant time.
8. remove_from_back()
Time Complexity: O(n)
Reasoning: Removing the last node requires traversing the list to find the node just before the last one, making the time complexity linear.
9. get_index_of_value(val)
Time Complexity: O(n)
Reasoning: The method might need to traverse the entire list to find the value, resulting in linear time complexity.
10. to_string()
Time Complexity: O(n)
Reasoning: The method needs to visit each node to construct the string representation of the list, making it a linear operation.
11. copy()
Time Complexity: O(n)
Reasoning: To copy the list, the method must traverse the entire list and create new nodes, resulting in a linear time complexity.
12. extend(other)
Time Complexity: O(n)
Reasoning: Extending a list involves traversing the entire other list and appending each node to the current list. This operation is linear in the size of other.
